## 📝 Problem Statement

> Given an array arr[], return the floor value of the mean of its elements.


## 📚 Examples

<details open>
<summary><strong>Example 1</strong></summary>

| | |
|---|---|
| **Input** | `arr[] = [1, 3, 4, 2, 6, 5, 8, 7]` |
| **Output** | `4` |

**Explanation:**
Sum of the elements is 1 + 3 + 4 + 2 + 6 + 5 + 8 + 7 = 36, Mean = 36/8 = 4.5, floor(4.5) = 4.

</details>

<summary><strong>Example 2</strong></summary>

| | |
|---|---|
| **Input** | `arr[] = [4, 4, 4, 4, 4]` |
| **Output** | `4` |

**Explanation:**
Sum of the elements is 4 + 4 + 4 + 4 + 4 = 20, Mean = 20/5 = 4


Constraints:
1 ≤ arr.size() ≤ 106
1 ≤ arr[i] ≤ 106
