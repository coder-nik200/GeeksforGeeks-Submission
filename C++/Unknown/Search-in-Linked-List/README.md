## 📝 Problem Statement

> Given the head of a singly linked list and an integer key, check if the key is present in the linked list or not.
> 
> Example:
> 
> Input: key = 3,
>       
> Output: true 
> Explanation: 3 is present in Linked List.
> Input: key = 4,
>    
> Output: false
> Explanation: 4 is not present in Linked List.
