## 📝 Problem Statement

> Given a string s, find if it is a palindrome. A string is considered a palindrome if it reads the same forwards and backwards.


## 📚 Examples

<details open>
<summary><strong>Example 1</strong></summary>

| | |
|---|---|
| **Input** | `s = "abba"` |
| **Output** | `true` |

**Explanation:**
"abba" reads the same forwards and backwards, so it is a palindrome.

</details>

<details >
<summary><strong>Example 2</strong></summary>

| | |
|---|---|
| **Input** | `s = "abc"` |
| **Output** | `false` |

**Explanation:**
"abc" does not read the same forwards and backwards, so it is not a palindrome.

</details>
