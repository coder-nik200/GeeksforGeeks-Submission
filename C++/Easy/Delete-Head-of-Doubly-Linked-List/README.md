## 📝 Problem Statement

> Given the head of a doubly linked list, delete the head node and return the new head of the list.


## 📚 Examples

<details open>
<summary><strong>Example 1</strong></summary>

| | |
|---|---|
| **Input** | `` |
| **Output** | `2 <-> 3` |

**Explanation:**
The first node [1] is removed, and the next node [2] becomes the new head.

</details>

<details >
<summary><strong>Example 2</strong></summary>

| | |
|---|---|
| **Input** | `head = [2, 5, 7, 8, 99, 100]` |
| **Output** | `5 <-> 7 <-> 8 <-> 99 <-> 100` |

**Explanation:**
The head node [2] is deleted, and the remaining list starts from node 5.
