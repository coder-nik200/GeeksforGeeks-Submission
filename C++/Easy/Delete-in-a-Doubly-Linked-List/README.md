## 📝 Problem Statement

> Given the head of a doubly linked list and an integer k, delete the node at the kth position (1-based indexing) and return the head of the modified list.


## 📚 Examples

<details open>
<summary><strong>Example 1</strong></summary>

| | |
|---|---|
| **Input** | `k = 3,` |
| **Output** | `1 <-> 3` |

**Explanation:**
After deleting the node at position 3 (position starts from 1), the updated linked list is 1 <-> 3.

</details>
