## 📝 Problem Statement

> Given a Linked List, delete the tail (i.e., the last node) of the Linked List and return the new head of the modified Linked List.


## 📚 Examples

<details open>
<summary><strong>Example 1</strong></summary>

| | |
|---|---|
| **Input** | `head[] = [1, 2, 3, 4, 5]` |
| **Output** | `1 -> 2 -> 3 -> 4` |

**Explanation:**
After deleting tail from the given linked list, we'll be left with just 1 -> 2 -> 3 -> 4.

</details>
