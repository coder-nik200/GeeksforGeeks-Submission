## 📝 Problem Statement

> Find the n-th Fibonacci number for a given non-negative integer n.
> The Fibonacci sequence is defined as:
> 
> F(0) = 0
> F(1) = 1
> F(n) = F(n - 1) + F(n - 2) for n ≥ 2
