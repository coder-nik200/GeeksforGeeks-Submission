## 📝 Problem Statement

> Given the root of a binary tree, determine if it is height-balanced or not.
> 
> Note: A binary tree is considered height-balanced if the absolute difference in heights of the left and right subtrees is at most 1 for every node in the tree.


## 📚 Examples

<details open>
<summary><strong>Example 1</strong></summary>

| | |
|---|---|
| **Input** | `root = [10, 20, 30, 40, 60]` |
| **Output** | `true` |

**Explanation:**
The height difference between the left and right subtrees at all nodes is at most 1. Hence, the tree is balanced.

</details>

<details >
<summary><strong>Example 2</strong></summary>

| | |
|---|---|
| **Input** | `root = [1, 2, 3, 4, N, N, N, 5]` |
| **Output** | `false` |

**Explanation:**
The height difference between the left and right subtrees at node 2 is 2, which exceeds 1. Hence, the tree is not balanced.

</details>
