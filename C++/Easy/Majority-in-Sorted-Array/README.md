## 📝 Problem Statement

> Given a sorted array arr[] of size n, determine whether there is a majority element in the array or not. An element is called a majority element if it appears more than n/2 times in the array.


## 📚 Examples

<details open>
<summary><strong>Example 1</strong></summary>

| | |
|---|---|
| **Input** | `arr[] = [1, 2, 3, 3, 3, 3, 10]` |
| **Output** | `true` |

**Explanation:**
The size of the array is 7. The middle element is arr[7/2] = arr[3] = 3. Element 3 appears 4 times. Since 4 > (7 / 2), it is a majority element.

</details>

<details >
<summary><strong>Example 2</strong></summary>

| | |
|---|---|
| **Input** | `arr[] = [1, 1, 2, 4, 4, 4, 6, 6]` |
| **Output** | `false` |

**Explanation:**
The size of the array is 8. The middle element is arr[8/2] = arr[4] = 4. Element 4 appears 3 times. Since 3 is not greater than (8 / 2), it is not a majority element.

</details>
