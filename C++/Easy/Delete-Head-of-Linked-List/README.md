## 📝 Problem Statement

> Given a Linked List, delete the head of the Linked List and return the new head of the modified Linked List.
> Note: Set the original head to NULL.


## 📚 Examples

<details open>
<summary><strong>Example 1</strong></summary>

| | |
|---|---|
| **Input** | `` |
| **Output** | `2 -> 3 -> 1 -> 7` |

**Explanation:**
After deleting head from the given linked list, we'll be left with just 2 -> 3 -> 1 -> 7.
