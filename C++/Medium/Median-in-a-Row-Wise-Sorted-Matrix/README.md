## 📝 Problem Statement

> Given a row-wise sorted matrix mat[][], where the number of rows and columns is always odd. Return the median of the matrix.


## 📚 Examples

<details open>
<summary><strong>Example 1</strong></summary>

| | |
|---|---|
| **Input** | `mat[][] = [[1, 3, 5], [2, 6, 9], [3, 6, 9]]` |
| **Output** | `5` |

**Explanation:**
Sorting matrix elements gives us [1, 2, 3, 3, 5, 6, 6, 9, 9]. Hence, 5 is median.

</details>

<details >
<summary><strong>Example 2</strong></summary>

| | |
|---|---|
| **Input** | `mat[][] = [[2, 4, 9], [3, 6, 7], [4, 7, 10]]` |
| **Output** | `6` |

**Explanation:**
Sorting matrix elements gives us [2, 3, 4, 4, 6, 7, 7, 9, 10]. Hence, 6 is median.

</details>

<details >
<summary><strong>Example 3</strong></summary>

| | |
|---|---|
| **Input** | `mat = [[3], [4], [8]]` |
| **Output** | `4` |

**Explanation:**
Sorting matrix elements gives us [3, 4, 8]. Hence, 4 is median.

</details>
