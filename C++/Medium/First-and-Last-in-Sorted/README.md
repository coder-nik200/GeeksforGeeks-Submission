## 📝 Problem Statement

> Given a sorted array arr[] with possibly some duplicates, find the first and last occurrences of an element x in the given array.
> Note: If the number x is not found in the array then return both the indices as -1.


## 📚 Examples

<details open>
<summary><strong>Example 1</strong></summary>

| | |
|---|---|
| **Input** | `arr[] = [1, 3, 5, 5, 5, 5, 67, 123, 125], x = 5` |
| **Output** | `[2, 5]` |

**Explanation:**
First occurrence of 5 is at index 2 and last occurrence of 5 is at index 5

</details>

<details >
<summary><strong>Example 2</strong></summary>

| | |
|---|---|
| **Input** | `arr[] = [1, 3, 5, 5, 5, 5, 7, 123, 125], x = 7` |
| **Output** | `[6, 6]` |

**Explanation:**
First and last occurrence of 7 is at index 6

</details>

<details >
<summary><strong>Example 3</strong></summary>

| | |
|---|---|
| **Input** | `arr[] = [1, 2, 3], x = 4` |
| **Output** | `[-1, -1]` |

**Explanation:**
No occurrence of 4 in the array, so, output is [-1, -1]
