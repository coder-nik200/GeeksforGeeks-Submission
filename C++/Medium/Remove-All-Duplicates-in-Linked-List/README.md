## 📝 Problem Statement

> Given a sorted linked list, remove all nodes that have duplicate values, retaining only nodes whose values appear exactly once. Return the head of the updated linked list.


## 📚 Examples

<details open>
<summary><strong>Example 1</strong></summary>

| | |
|---|---|
| **Input** | `head = 23 -> 28 -> 28 -> 35 -> 49 -> 49` |
| **Output** | `23 35` |

**Explanation:**
The duplicate numbers are 28 and 49 which are removed from the list.

</details>

<details >
<summary><strong>Example 2</strong></summary>

| | |
|---|---|
| **Input** | `head = 11 -> 11 -> 75 -> 75` |
| **Output** | `Empty list` |

**Explanation:**
All the nodes in the linked list have duplicates. Hence the resultant list would be empty.
Constraints:
1 ≤ node->data ≤ 109
1 ≤ number of nodes ≤ 105

</details>
