## 📝 Problem Statement

> Given an array arr[] of non-negative integers. Find length of the longest sub-sequence such that elements in the subsequence are consecutive integers, the consecutive numbers can be in any order.


## 📚 Examples

<details open>
<summary><strong>Example 1</strong></summary>

| | |
|---|---|
| **Input** | `arr[] = [2, 6, 1, 9, 4, 5, 3]` |
| **Output** | `6` |

**Explanation:**
The consecutive numbers here are 1, 2, 3, 4, 5, 6. These 6 numbers form the longest consecutive subsquence.

</details>

<details >
<summary><strong>Example 2</strong></summary>

| | |
|---|---|

| **Output** | `4` |

**Explanation:**
1, 2, 3, 4 is the longest consecutive subsequence.

</details>

<details >

| **Output** | `7` |

**Explanation:**
The longest consecutive subsequence is 9, 10, 11, 12, 13, 14, 15, which has a length of 7.
