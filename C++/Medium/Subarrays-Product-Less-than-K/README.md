## 📝 Problem Statement

> Given an integer array arr[] of positive numbers, the task is to find the number of possible contiguous subarrays having product less than k.


## 📚 Examples

<details open>
<summary><strong>Example 1</strong></summary>

| | |
|---|---|
| **Input** | `k = 100, arr[] = [1, 9, 2, 8, 6, 4, 3]` |
| **Output** | `16` |

**Explanation:**
There are 16 contiguous subarrays whose product of elements is strictly less than 100. 

Constraints:
1 ≤ n ≤ 105
1 ≤ k ≤ 105
1 ≤ arr[i] ≤ 103
