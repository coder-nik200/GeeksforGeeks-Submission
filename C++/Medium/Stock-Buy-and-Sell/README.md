## 📝 Problem Statement

> Given an array arr[] denoting the cost of stock on each day, the task is to find the maximum total profit if we can buy and sell the stocks any number of times.
> 
> Note: We can only sell a stock which we have bought earlier and only one instance of stock can be traded.


## 📚 Examples

<details open>
<summary><strong>Example 1</strong></summary>

| | |
|---|---|
| **Input** | `arr[] = [100, 180, 260, 310, 40, 535, 695]` |
| **Output** | `865` |

**Explanation:**
Buy the stock on day 0 and sell it on day 3 => 310 – 100 = 210 Buy the stock on day 4 and sell it on day 6 => 695 – 40 = 655 Maximum Profit  = 210 + 655 = 865

</details>

<details >
<summary><strong>Example 2</strong></summary>

| | |
|---|---|
| **Input** | `arr[] = [4, 2, 2, 2, 4]` |
| **Output** | `2` |

**Explanation:**
Buy the stock on day 3 and sell it on day 4 => 4 – 2 = 2

</details>

<details >
<summary><strong>Example 3</strong></summary>

| | |
|---|---|
| **Input** | `arr[] = [4, 2]` |
| **Output** | `0` |

**Explanation:**
Don't Buy the stock.

</details>
