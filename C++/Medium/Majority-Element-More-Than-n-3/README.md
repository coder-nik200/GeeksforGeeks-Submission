## 📝 Problem Statement

> Given an array arr[] consisting of n integers, find all the array elements which occurs more than floor(n/3) times. Return the resulting array in strictly increasing order. If no such elements exist, return an empty array.


## 📚 Examples

<details open>
<summary><strong>Example 1</strong></summary>

| | |
|---|---|
| **Input** | `arr[] = [2, 2, 3, 1, 3, 2, 1, 1]` |
| **Output** | `[1, 2]` |

**Explanation:**
The frequency of 1 and 2 is 3, which is more than floor n/3 (8/3 = 2).

</details>

<details >
<summary><strong>Example 2</strong></summary>

| | |
|---|---|
| **Input** | `arr[] = [-5, 3, -5]` |
| **Output** | `[-5]` |

**Explanation:**
The frequency of -5 is 2, which is more than floor n/3 (3/3 = 1).

</details>

<details >
<summary><strong>Example 3</strong></summary>

| | |
|---|---|
| **Input** | `arr[] = [3, 2, 2, 4, 1, 4]` |
| **Output** | `[]` |

**Explanation:**
There is no majority element.

</details>
